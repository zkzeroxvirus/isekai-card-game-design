# v0.2.20 — Cohesive Progression Architecture & Isekai Quality Checklist

## Summary

This patch consolidates the growing progression stack into six player-facing domains, introduces the Discipline Development Grid as the principal point-based specialization system, and adds a project-wide quality checklist for preserving the intended isekai choose-your-adventure fantasy.

It also replaces obsolete turn-based rules in `RULES_FRAMEWORK.md` with the current real-time action-RPG architecture.

## Added

### `docs/COHESIVE_PROGRESSION_ARCHITECTURE.md`

Defines six player-facing progression domains:

1. Character
2. Combat Build
3. Role
4. Gear
5. Discovery
6. World

Locks the following architecture:

- Skills improve primarily through meaningful use/training.
- Development Points are the primary conventional point-spending currency.
- Development Points mainly customize compact Discipline Development Grids.
- Mature Discipline Grids target roughly 20–35 meaningful nodes rather than giant universal passive webs.
- Vertical-slice Discipline Grids should prototype only about 6–10 nodes each.
- Node families include Connector, Behavior, Build, Keystone, Bridge, and Hidden Nodes.
- Multiclass Bridge Nodes connect compatible Discipline specializations after qualification.
- Hidden Nodes can reveal themselves through behavior, mastery, Jobs, world state, equipment, narrative history, or System Comprehension.
- Jobs do not receive giant point trees; they develop through activity, location, institutions, cultures, and hidden qualification.
- Equipment uses one consistent mastery/evolution language.
- Achievements and Titles are supporting systems rather than primary power ladders.
- Treasures remain rare and rule-changing.
- Knowledge and System Comprehension form the Discovery domain.
- Covenants, Compound Manifestations, and Domains remain advanced Codex mechanics rather than separate base systems.
- Authorities remain rare endgame/lore architecture.
- Temporary expedition progression remains lighter than persistent character development.

### `docs/ISEKAI_GAME_QUALITY_CHECKLIST.md`

Adds a design checklist covering:

- moment-to-moment fun
- isekai world-entry fantasy
- meaningful agency
- world complexity and readability
- discovery
- identity-driven progression
- progression clarity / bloat control
- isekai power curve
- settlements and regions
- quest quality
- NPCs and companions
- dungeon quality
- combat understanding and counterplay
- failure
- multiplayer
- mystery
- choose-your-adventure play
- pacing
- respect for player time
- systemic surprise
- Hearthcross vertical-slice acceptance criteria

Defines the project essence as:

> A choose-your-adventure life inside a complex fantasy world where the player arrives vulnerable, discovers how the world works, builds an identity through actions, and eventually becomes capable of exploiting rules that once constrained them.

## Updated

### `docs/RULES_FRAMEWORK.md`

Rewritten from the obsolete turn-based v0.2.0 rules into the current v0.2.20 real-time architecture.

Removed or superseded:

- turn-based player/enemy turn loop
- 3-Action turn resource
- 10-card turn-based hand assumptions
- unnecessary Prepared/In Play zone assumptions
- strict Town Phase / Dungeon Run structure as the only macro loop

Current rules now include:

- real-time third-person combat
- Foundation Actions + Weapon Arts + Codex Manifestations
- five-slot Active Codex hand
- Discipline resources
- Development Grids
- Skills and Jobs
- location-based Job discovery
- hidden progression
- equipment mastery/evolution
- Knowledge/System Comprehension
- world-state consequences
- limited temporary expedition progression
- real-time manifestation resolution and targeting families
- 1–6 player co-op architecture
- advanced rule manipulation folded under Codex Manifestations

## Production Rule

The vertical slice remains the implementation priority.

Do not implement complete mature Discipline Grids, full multiclass bridge networks, Covenants, Domains, Authorities, or large Job evolution webs until the base movement, combat, Codex loop, Hearthcross, Greyfen, Buried Gate, persistence, and first hidden-progression interactions are fun together.
