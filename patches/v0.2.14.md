# v0.2.14 — First Combat Package

## Added

- Added the first complete playable combat package: **Guardian + Arming Sword & Shield**.
- Formalized Guardian's active-defense resource, **Resolve**.
- Added Weak Guard, Solid Guard, and Perfect Guard outcomes.
- Added the first reliable Weapon Art package: Advancing Slash, Shield Bash, Intercept, and Counterstep.
- Added the first five-card Guardian manifestation package: Brace, Shield Counter, Guardian's Advance, Hold Fast, and Severing Riposte.
- Added same-slot transformation testing through Brace → Perfect Guard.
- Added explicit cross-player status synergy through Severing Riposte.
- Defined Guardian as a physical interception/space-control discipline rather than an MMO threat-table tank.
- Added mastery examples for Shield Bash and Intercept.
- Added the first equipment-evolution example: Hearthcross Militia Shield → Gatewarden Shield.
- Connected The Stranded and The Invited Origins to different routes into Guardian development.
- Updated Gatebound Hob requirements so the first boss deliberately tests blocking, dodging, interception, stagger, and co-op support.

## Core Prototype Principle

**Reliable weapon play must already feel good before the Codex appears; manifestations then deepen, transform, and exploit that combat vocabulary.**
