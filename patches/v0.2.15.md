# v0.2.15 — Arcanist Ranged/Magic Combat Package

## Added

- Added **Arcanist** as the second fully specified prototype discipline.
- Added **Channeling Staff & Arcane Focus** as the first ranged/magic weapon package.
- Added the **Attunement** discipline mechanic, earned through successful magical sequencing, Sigil interaction, exploiting weaknesses, and disrupting empowered actions.
- Added reliable ranged baseline actions: **Arc Bolt**, **Focused Lance**, and **Focus Guard**.
- Added reliable Weapon Arts: **Sigil Cast**, **Arc Step**, **Disrupting Pulse**, and **Threaded Shot**.
- Added compact persistent-in-combat **Sigils** as spatial anchors that can modify projectiles and be transformed or consumed by manifestations.
- Added the first five Arcanist manifestations: **Ember Rune**, **Detonate Sigil**, **Mana Thread**, **Gravitic Snare**, and **Arc Lance**.
- Added Guardian + Arcanist cross-player synergy examples using Burning, Exposed, Marked by Mana, and stagger windows.
- Added Arcanist-specific Greyfen and Gatebound Hob encounter requirements.
- Added mastery examples for Sigil Cast and Arc Step.
- Added the equipment evolution path **Hearthcross Survey Staff → Gate-Echo Staff**.
- Added controller/keyboard ground-targeting and multiplayer VFX-readability requirements.

## Design Direction

The second discipline deliberately contrasts Guardian.

Guardian rewards timing, interception, and defense-to-offense conversion.

Arcanist rewards range control, aim, spatial setup, elemental/status interaction, and prepared magical sequencing.

The shared combat framework should therefore prove that reliable Weapon Arts plus rotating Codex manifestations can support radically different playstyles without requiring every class to use the same action pattern.

## Locked Principle

**Magic should shape the battlefield, not merely replace arrows with colored projectiles.**

Arcanist's Sigils, projectile threading, control fields, elemental modification, and Attunement loop establish this direction while keeping basic ranged combat functional before any Codex card is drawn.
