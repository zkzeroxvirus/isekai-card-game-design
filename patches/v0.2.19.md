# v0.2.19 — Playable Demo Scope

This patch pauses broad feature expansion and converts the current Hearthcross/Greyfen/Buried Gate design into a focused vertical-slice demo target.

## Added

- `docs/PLAYABLE_DEMO_SCOPE.md`
- one complete demo flow: The Stranded → Hearthcross → Greyfen contract → Buried Gate → Gatebound Hob → Story Revelation → persistent return state
- hard scope freeze separating demo requirements from deferred full-game systems
- reduced demo Job roster proving location-based discovery
- one attainable hidden Job plus one teaser hidden path
- staged multiplayer target: host + one client first, architecture compatible with eventual 1–6 players
- explicit technical milestones from movement/combat sandbox through persistence and polish
- demo success criteria focused on proving that combat, Codex, Skills, Jobs, world state, dungeon play, and narrative mystery work together

## Demo Combat Scope

The three benchmark Disciplines remain:

- Guardian — Arming Sword & Shield
- Arcanist — Staff & Arcane Focus
- Duelist — Twin Blades

Each retains its reliable Weapon Arts, Discipline resource, and compact manifestation package.

## Demo World Scope

The demo centers exclusively on:

- The Stranded Origin prologue
- Hearthcross
- one Greyfen field route and consequential goblin encounter
- The Buried Gate
- Gatebound Hob
- the first Gate recognition Story Revelation

## Production Rule

**Do not add a new major system until the vertical slice demonstrates that the existing systems are fun together.**

New ideas can still be documented for backlog use, but implementation priority remains the Hearthcross vertical slice.
