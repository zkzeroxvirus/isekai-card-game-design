# v0.2.12 — Playable Origins & Opening Scenarios

## Added

- Five standard starting Origins: Accidental Transfer, Ritual Summon, Reincarnated, Failed Hero Summoning, and Divine Bargain.
- One later-unlocked System Anomaly Origin.
- Separate Origin and previous-world Background layers.
- Origin-specific Threshold presentations, starting Skills, System Comprehension, Codex reveal timing, support level, and long-term hooks.
- Adaptive first-manifestation pool based on Origin, Background, Skills, and player behavior.
- Shared opening convergence into a common frontier region while preserving persistent Origin consequences.
- Multiplayer unlock after the personal prologue reaches the shared regional structure.

## Prototype Scope

The first onboarding prototype should fully implement:

1. Accidental Transfer — The Stranded
2. Ritual Summon — The Invited

These provide a strong contrast between survival-first/low-information and institution-supported/system-aware onboarding while sharing the same underlying combat and progression systems.

## New Principle

**Every Origin teaches the same world through a different lens.**
